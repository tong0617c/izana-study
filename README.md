# IZANA · 私人自习室

适配手机的黑白漫画伴学网页。原生 HTML/CSS/JavaScript，无构建依赖。

## 功能

- 全屏角色开场、逐字对话、学习时 Q 版陪伴和定时短句。
- 课文：阅读标注 → 关键词填空 → 提示词复述 → 原文自查。
- 单词：点击翻面、熟悉度选择、不熟悉词本轮重排。
- 科学：阅读 → 书写复述笔记 → 原文对照。
- 材料管理、台词编辑、学习历史、完整 JSON 导入导出。
- Supabase 邮箱密码登录、独立账号资料库、跨设备同步。
- 老师发布教材库、学生邀请码加入、老师检查原始笔记和学习状况并留下批注。
- 云同步按条目修改时间合并；服务端乐观锁防止跨设备覆盖。相同材料同时编辑时最后修改版本胜出。

## 使用已部署的版本

云项目已经预置。打开 https://tong0617c.github.io/izana-study/，在「内容管理 → 账号与跨设备同步」注册邮箱账号。按项目所有者选择，已关闭邮箱确认，注册后即可使用；手机和电脑登录同一账号即可同步。请记好密码，目前未配置邮件找回。

### 补习流程

1. 老师先注册并登录，在「内容管理」录入教材。
2. 点击「我是老师 · 发布教材库」，复制邀请码发给学生。只发布教材原文和关键词，不发布老师的私人笔记。
3. 学生注册自己的账号，点击「我是学生 · 邀请码加入」，输入姓名并同意分享本班作业。
4. 学生从自习室选择教材学习，笔记自动保存并同步。结束后保存完成记录。
5. 老师在「学生学习状况」点击「查看笔记与批改」，检查作答并留下订正建议。
6. 学生在补习室面板查看批注。点击「刷新补习室」立即获取最新教材或批注。

老师仅能查看已加入本班的学生提交的本班作业；学生其他私人材料不会上传给老师。老师删除教材后，会从学生学习列表下架，但保留已有笔记与完成记录。

GitHub / Supabase 控制台账号与网页里的学习账号是不同用途；网页账号需要首次注册。

## 在自己的新项目重新部署登录和同步

1. 创建 Supabase 项目，在 SQL Editor 依次执行 `supabase.sql`、`classroom.sql`。
2. Authentication → Providers 启用 Email；保留邮箱确认。
3. Authentication → URL Configuration 将 Site URL 设置为部署后的页面地址。
4. 项目 Settings → API 获取 Project URL 和 publishable/anon 公共密钥。
5. 网页「内容管理」填写地址和公开密钥，保存后注册、邮件确认、登录。
6. 另一台设备填写相同配置并登录同一账号即可同步。默认内置邮件服务限制收件人，面向外部学生若保留邮箱验证，需要自行配置 SMTP。

不要将 service_role / secret key 写入网页或仓库。资料表开启行级安全，读写均限定 auth.uid()。
访客与各账号本机数据隔离；迁移访客数据时，先导出、登录、再导入。
建议定期备份，浏览器清理会移除尚未同步的本地数据。
账号 token 保存在当前浏览器，不要在共享设备保持登录。

## 本地运行

`node server.cjs` 后访问 `http://localhost:4173`。
手机可在相同网络通过电脑局域网 IP 访问（需操作系统允许该端口），正式使用建议 HTTPS 部署地址。

## 素材与台词

四张图片由用户提供，属于《东京复仇者》角色同人学习项目，保留原图。仅用 CSS 灰度呈现。
角色台词为本项目原创同人情境，不是官方引文；可自行修改。
本项目无官方关联。字体从 Google Fonts 加载，网络不可用时使用系统字体。

## 验证

`node test.cjs` 验证文本处理、同步合并、导入校验、共享教材字段隔离。
`test-database.sql` 在事务内检查老师、学生、陌生账号权限和并发版本保护，最后回滚全部测试数据。
